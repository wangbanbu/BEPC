# BEPC 独立代码优化与有限救援实验

冻结日期：2026-11-01。旧实验目录 `../single_pass/` 及实际方法源码 `../harness/` 只读；新的代码、运行记录、评测缓存和报告全部保存在本目录。

## 目标和比较

检验两件独立的事：工程优化是否在相同接受决策和生成 token 下减少实际时延；保持 BEPC 双向、有界 Margin 修正思想，仅适度增强救援方向，是否能改善接受长度/吞吐而维持任务表现。

| 方法 | 代码与改变 |
|---|---|
| strict_shared | 上轮共享工程优化的 Strict ViSpec，逐字复制代码 |
| bepc_original | 上轮实际 BEPC 参数和控制器，逐字复制代码 |
| bepc_fast | BEPC 参数不变；每题4次 mismatch 预算用尽后退出专用观察器和 Margin 修正，执行等价严格选择 |
| bepc_rescue0625 | 在 bepc_fast 上只将 rescue gamma 从0.5提高至0.625；protection gamma仍为0.5 |

后三种方法保持 U8/P4、W32、视觉池64、最终原生 Margin、tau=1、kappa=1、eta=1e-4、关闭残差衰减，每轮2次/每题4次 mismatch 预算。图像方向/文本方向只是状态几何代理。没有训练、信号融合、新的模型前向或强制修改答案。

令 g=z_target_top1-z_draft，v=min(|m_U|,|m_P|,1)。在空间有效、数值有限且方向冲突、分量强度满足既有门限时：rescue (m_U<0,m_P>0) 的 delta=gamma_rescue*v；protection (m_U>0,m_P<0) 的 delta=-0.5*v。其余 delta=0。接受条件仍为 g-delta<=1。工程臂 gamma_rescue=0.5；有限放宽臂为0.625。只扩大救援分支的局部接受范围，并不意味着整个生成轨迹的质量或接受长度单调改善。

全局预筛必须使用非对称修正上下界 [-0.5,0.625]；视觉预筛依据 m_U 的符号确定可用方向。边界数值不确定时完整计算。既有 EOS mismatch 保护、可见边界、首条最长前缀 tie-breaking 必须保持。预算耗尽后的快速路径不能重新从原始 prompt 开始 Strict，而应在当前实际生成前缀上继续原生验证。

## 数据与运行

ScienceQA、COCO、TextVQA 各20个开发样本和100个测试样本，直接使用上轮 SHA 冻结的同一图像/问题/原始长输出 Prompt。不重抽样、不删除困难/失败样本。100组已经被上轮实验使用，因此是配对复测，不称为独立新测试集。

沿用 Qwen2.5-VL-7B-Instruct / ViSpec checkpoint、T=0/seed0、原生树30/depth3/topk8/num_q2（实际29节点）、512-token预算、原来 EOS/after-block stop、原有图像处理和 BF16 前向。所有任务只测一遍，按原来的图像分片规则在两张L20上运行。每个问题内随机化四种方法顺序，每方法/任务/进程做一次不计分热身；图像预处理按上轮约定在同题方法间复用。

共240次开发生成、1200次测试生成。开发阶段用于检查新旧 BEPC 的 raw token、可见 token、每轮接受长度和选中路径完全一致；固定0.625参数在读取新质量结果前确定，不进行开发/测试阈值选择。主测试仍执行同一逐题等价断言。若工程等价失败，保存失败证据并修复，不能把结果差异解释为工程收益。

上轮各方法数据仅作为历史参照。主要速度比较使用本轮同场 original/fast/rescue/strict 结果，不将不同时段的时延直接当作加速因果证据。

## 指标与质量边界

主速度指标：完整模型请求时延及内容 token/s（包含视觉编码、prefill、特征/验证和解码；预处理/H2D按旧口径另记）。同时报告 native/effective MAT、输出长度、峰值 allocated/reserved 和增量显存、额外 Target forward 数量、EOS和截断。

ScienceQA：原来固定末行 `Final answer:` 解析器和官方多选 Accuracy。TextVQA：同一固定解析器和官方 VQA-style accuracy。解析失败保留分母并按0分，解释段质量未被这些分数验证。

COCO：完整长输出，不截第一句；官方 CIDEr-D、SPICE、CHAIR，沿用相同参考、对象词典、场景图评测。长段落 CIDEr-D 的长度惩罚可能使其极小，只作辅助解释；不从其下降推导事实伤害。不调用自动 Judge 生成新 GT。人工图像条件成对审核仍缺失，不能宣称完整事实质量保真。

SPICE 预设所有新计算使用同一官方实现和64GiB Java heap，以避免已知16GiB长输出资源失败；这仅改变CPU资源，不改变解析器/参考/评分规则，也不计入GPU生成时延。只允许在样本、文本和评测实现完全一致并记录来源时复用历史官方分数。

预先声明的自动任务非劣效探索门槛：ScienceQA/TextVQA 相对本轮 Strict、相对原BEPC分别最大下降2个百分点；COCO SPICE最大下降5%（相对），CHAIRs最大增加2个百分点（绝对）。采用图像分组bootstrap单侧95%界；所有适用约束均通过才可在这些自动指标范围内称通过。2pp/5%是本实验的研究容忍范围，不是原论文定义的 Harmful 阈值。100组可能不足以建立非劣效，未检出显著差异不表示通过。

## 统计与解释

按 image_id 成组、5000次配对bootstrap，种子沿用上轮；报告配对差值、比值、双侧95%CI和质量单侧界。预先比较 fast-original、rescue-fast、rescue-strict；原BEPC和新放宽臂对 Strict 的质量同时报告。不得按测试结果改变风险方向、Gamma、预算或挑选最有利指标。

一次计时只刻画固定运行记录和图像组成不确定性，不能估计重复运行噪声。质量约束、吞吐/MAT及整题时延分开判定；不因 MAT 更大就称实际更快。保留所有负结果、失败、分歧和无效事件；缺少人工审核与新图像评测时，最终结论限于本次三任务既有子集。
